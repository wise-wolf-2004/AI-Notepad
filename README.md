# 📝 AI Notepad

AI Notepad is a full-stack web application that combines **note-taking** with **AI-powered summarization and suggestions**.  
Users can create, update, delete, and view notes while leveraging AI to **summarize notes** and provide **smart suggestions**.

---

## 🚀 Features

- ✍️ **CRUD Operations** – Create, Read, Update, and Delete notes.  
- 🤖 **AI Summarization** – Hugging Face API generates concise summaries of notes.  
- 💡 **AI Suggestions** – Provides actionable insights and suggestions based on note content.  
- 🌙 **Theme Switcher** – Toggle between light and dark mode.  
- 🎨 **Modern UI** – Clean and responsive React-based interface.  

---

## 🛠️ Tech Stack

**Frontend:**  
- React  
- Axios (for API calls)  
- CSS / Tailwind (depending on your styling)

**Backend:**  
- Node.js  
- Express.js  
- Axios (for Hugging Face API requests)

**Database:**  
- MongoDB (Mongoose ODM)

**AI Integration:**  
- Hugging Face Inference API
